# Review of Probability and Statistics

Course materials for the **Review of Probability and Statistics**, taught at the
Yale School of Management for students in the **Master of Management Studies in
Asset Management (MAM)** programme.

The review runs as a three-part sequence that takes students from "what is a
random variable" through to hypothesis testing, using financial data throughout.

---

## Slides

The Beamer `.tex` source is the single source of truth for all content. Decks
live in `drafts/slides/`.

| Deck | File | Frames | Covers |
|------|------|--------|--------|
| Part 1 | `part1_random_variables.tex` | 35 | Data generating processes, random variables, discrete vs continuous, pmf/pdf/cdf, the normal distribution, Bernoulli and Binomial, fat tails in real returns |
| Part 2 | `part2_moments.tex` | 26 | Expected value and the law of large numbers, variance and standard deviation, covariance and correlation, portfolio return and variance, skewness and kurtosis |
| Part 3 | `part3_inference.tex` | 42 | Populations and samples, estimators, standard errors, the central limit theorem, hypothesis testing, $p$-values, confidence intervals |

Part 2 is built around a single running question — how to split a portfolio
between stocks and bonds — and Part 3 around whether Warren Buffett's record is
skill or luck.

### Supporting LaTeX

`drafts/latex_files/` holds everything the decks pull in:

- `header_slides.tex` — the Beamer preamble: theme, the Okabe–Ito colour
  palette, custom boxes (`questionbox`, `answerbox`, `insightbox`,
  `definitionbox`, `methodbox`, `quotebox`), and shared math macros
- `header_doc.tex` — preamble for non-Beamer documents
- `references.bib`, `aea.bst` — bibliography and style
- `slides_template.tex`, `doc_template.tex` — starting points for new files

### Compiling

XeLaTeX, three passes with BibTeX in between. Run from `drafts/slides/`:

```bash
cd drafts/slides
TEXINPUTS=../latex_files: xelatex -interaction=nonstopmode part1_random_variables.tex
BIBINPUTS=../latex_files: bibtex part1_random_variables
TEXINPUTS=../latex_files: xelatex -interaction=nonstopmode part1_random_variables.tex
TEXINPUTS=../latex_files: xelatex -interaction=nonstopmode part1_random_variables.tex
```

Three passes are required: some frames use `equal height group`, which only
settles on the second pass.

## Code

Every figure in every deck is generated by R. Nothing is drawn by hand, and no
figure is edited after generation — to change a figure, change the script and
re-run it.

| Script | Lines | Figures | Feeds |
|--------|-------|---------|-------|
| `scripts/R/part1_figures.R` | 913 | 27 | Part 1 |
| `scripts/R/part2_figures.R` | 871 | 17 | Part 2 |
| `scripts/R/part3_figures.R` | 1253 | 26 | Part 3 |

Each script is run from the project root and writes PDFs to `output/figures/`:

```bash
Rscript scripts/R/part1_figures.R
```

Every script ends by printing the numbers that appear on the slides, so the
`.tex` can be checked against them after any regeneration.

Shared plotting setup lives in `scripts/R/theme.R`, which defines `theme_custom()`
and the Okabe–Ito colour constants. Those colours are kept identical to the ones
defined in `header_slides.tex`, so a `\textcolor{orange}` reference in the slide
text points at the same colour as the curve it describes.

### Data

All three scripts read only from `data/raw/`:

| File | Used for |
|------|----------|
| `stocks_bonds.csv` | Monthly US stocks, 10-year Treasuries and T-bills, 1926–2023. Part 1's up-month probability, Part 2's covariance and correlation, Part 3's equity premium |
| `shiller/ie_data.xls` | Robert Shiller's monthly series, 1871–2026. Part 1's return distribution and fat tails; Part 2's higher moments |
| `berkshire_market_monthly.csv` | Berkshire and market excess returns, 1976–2023. The Buffett hypothesis test in Part 3 |

Raw data is never modified — all transformations happen in the scripts.

Note that `ie_data.xls` stores its date as a numeric `YYYY.MM`, so October reads
as `.1`. Recover the month by rounding, never by slicing the string;
`data/raw/shiller/README.md` has the details.
